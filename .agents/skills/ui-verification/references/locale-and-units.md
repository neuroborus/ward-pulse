# Locale and unit defects

Use for a reported locale/region/unit mismatch or missing explicit unit designation.
Choose the actual cases needed to reproduce the incident and support the claimed repair;
do not expand the task into a Cartesian matrix of unrelated settings and targets.

## Establish the preference and selected source

For each relevant native case, record the actual target, effective locale/region, explicit
unit preference and where it is selected, plus installed artifact and active rendition
identities from [State and artifact identity](state-and-artifacts.md). Distinguish language
and region defaults from an explicit device/provider unit preference. A plausible number,
language tag or undocumented numeric setting does not prove the selected unit. Keep an
unavailable setting or identity Pending rather than inferring it.

Identify the source actually selected at observation time. For a face, distinguish built-in
WFF `WEATHER.*` chrome from an assigned complication using the current binding, provider
component and data type where observable. Generator defaults and package presence do not
establish a retained face's selected source. A current binding does not reconstruct the
original binding; a redacted value or null title does not establish the visible reading.
Keep unavailable source/binding ownership Pending.
If preferences or sources change, record separate before/after cases without attributing
the new result to the original path.

## Verify the requested designation

Read the expected unit designation from the owner's request and owning contract, then
inspect its exact visible glyphs in the original native frame. A degree sign alone does
not satisfy a requested explicit Celsius designation. Preview dashes or a provider's
selected-unit control do not establish what the installed face displays.

A default `en-US`/Fahrenheit example and a correct enum-to-label source branch do not cover
an incident requiring the explicitly preferred Celsius case at runtime. Run the relevant
actual preference/source/artifact case before accepting that result. An emulator witness
covers its recorded emulator settings and source only; keep unrun physical or explicit-unit
cases Pending. Compare readings across sources/times only when their equivalence is proved.

Preserve the observed mismatch separately from any proposed cause or formatting change.
Use existing authorized device/emulator operations for observations; this reference does
not prescribe locale changes, conversions, a new product setting or a provider replacement.
