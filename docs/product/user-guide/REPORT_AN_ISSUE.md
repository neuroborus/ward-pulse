# Report an issue

Use the format below when [opening a GitHub issue](https://github.com/neuroborus/ward-pulse/issues/new).
Sign in to GitHub if prompted. **Actual behaviour**, **Expected behaviour** and **Steps to
reproduce** are required; **Notes** is optional.

## Actual behaviour

Describe what happened, where it happened and the visible result. Include the affected
screen or provider row and any relevant status or update time. Explain what was missing,
incorrect or blocked rather than only saying that it did not work.

## Expected behaviour

Describe the result you expected from the same action. For example, say which screen should
open, which setting should be kept or which reported value should appear.

## Steps to reproduce

Give numbered steps from a clear starting point. Name the controls you used and the step
where the result differs from what you expected. Include conditions needed to reproduce
the problem, such as offline use or a particular widget size.

## Notes

Optional details include the WardPulse version, phone/watch OS, affected provider and a
safe screenshot. Hide account labels and private usage figures before sharing images.
Never include API keys, session cookies, authorization codes, account identifiers, prompts,
full provider responses or sensitive logs.

## Copy the format

Copy this template into the issue body. Remove **Notes** if it is not needed.

```markdown
## Actual behaviour
Describe what happened and where.

## Expected behaviour
Describe the result you expected.

## Steps to reproduce
1. Start from…
2. Tap…
3. Observe…

## Notes
Optional relevant context or a safe screenshot.
```
