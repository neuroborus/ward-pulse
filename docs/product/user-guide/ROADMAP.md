# Roadmap

Planned milestones for WardPulse. No release dates are set.

## Release 0.1.0

The first public release for Android phone and Wear OS, including the home widget and
watch face.

## Multi-account

Connect more than one account from the same provider and keep their usage separate.

## iOS release

WardPulse on iPhone. A later milestone than multi-account support.

## Agent Bridge (MCP)

Receive important messages from your AI agents in WardPulse over MCP. Sending replies is
still an open question.

This would require a WardPulse cloud account and access key, even for one-way notifications.

Question marks leave room for unannounced milestones.

What comes next is not revealed yet.
