# Roadmap

Planned milestones for WardPulse.

## Release 0.1.0

The first public release for Android phone and Wear OS, including the home widget and
watch face.

## Multi-account

Connect more than one account from the same provider and keep their usage separate.

## iOS release

WardPulse on iPhone.

## Agent Bridge (MCP)

Receive important messages from your AI agents in WardPulse over MCP.

This would require a WardPulse cloud account and access key.
