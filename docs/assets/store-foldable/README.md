# Foldable store gallery

Upload the images in order to **Main store listing → Graphics → Foldable Screenshots**
in Google Play Console. The cover goes first, followed by the six native captures.
[Google Play preview asset requirements](https://support.google.com/googleplay/android-developer/answer/9866151?hl=en#screenshots)

All seven files follow the owner's current upload set, supplied on 2026-11-25 and added to the
repository on 2026-11-28. Slots 1–6 are byte-identical to the supplied copies. Slot 0 is the
supplied cover with its watch face replaced on 2026-11-28, as described below. All are RGB PNGs in
the dark theme with the same sample usage data. The PNG metadata of slots 1–6 records image
processing on 2026-11-25 (Europe/Paris): slot 5 at 15:24, slot 6 at 15:43 and slots 1–4 between
15:57 and 16:00. The images show the inner square, inner wide and outer display layouts. The capture
device and app build are not recorded.
