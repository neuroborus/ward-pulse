Upload the images in order to **Main store listing → Graphics → Foldable Screenshots**
in Google Play Console. The optional cover goes first, followed by the three native captures.
[Google Play preview asset requirements](https://support.google.com/googleplay/android-developer/answer/9866151?hl=en#screenshots)

All three native images were captured, added, and reviewed on November 22, 2026 (Europe/Paris).
They show the same seeded demonstration data in the dark theme of the WardPulse 0.1.0 debug
build. The app rendered each full display directly in disposable Android 16 emulator sessions,
using 376, 288, and 480 dpi respectively. The guest display overrides show the layout at the three sizes.
Physical folding behavior and eligibility for a Google Play badge require separate verification.
