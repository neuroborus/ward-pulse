# Wear OS store gallery

Sample usage data is shown throughout. The captures use the fixed dark appearance of the
Wear app and watch face. Files were added and reviewed on 2026-11-22. Glance and Plan
windows were captured in one session on the round Wear emulator on 2026-11-22.

| Slot | File | Content |
| --- | --- | --- |
| 0 | [Promotional cover](0-cover.png) | 1254 × 1254 RGB art with the watch face, Glance and phone Dashboard in illustrated, unbranded hardware. |
| 1 | [Glance](1-glance.png) | 384 × 384 RGB emulator capture showing remaining capacity and purchased credits. |
| 2 | [Plan windows](2-plan-windows.png) | 384 × 384 RGB emulator capture showing a reported allowance and its reset time. |

Use slots 1 and 2 in the Google Play Wear OS screenshot gallery. Slot 0 is promotional art.
Google Play requires the Wear screenshot gallery to show only the app interface.
[Google Play preview asset requirements](https://support.google.com/googleplay/android-developer/answer/9866151?hl=en-GB)
