# WardPulse advertising assets

These images use actual WardPulse screens with sample usage and anonymous device illustrations.
The [WardPulse brand usage rules](../../../brand/README.md#usage-rules) apply to this artwork.

## Google Play

| Asset | Dimensions | Description |
| --- | --- | --- |
| [Feature Graphic](google-play/feature-graphic.png) | 1024 × 500 | WardPulse wordmark and the usage dashboard on an unfolded device. |

The device and interface come from the [Foldable store cover](../store-foldable/0-cover.png).
Use the graphic in the Feature Graphic field. [Play Console graphics requirements](https://support.google.com/googleplay/android-developer/answer/9866151)

call to action in Reddit Ads Manager. Preview the placement with the intended destination.
