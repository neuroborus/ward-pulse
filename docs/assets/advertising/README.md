# WardPulse advertising assets

These images use actual WardPulse screens with sample usage and anonymous device illustrations.
The [WardPulse brand usage rules](../../../brand/README.md#usage-rules) apply to this artwork.

## Google Play

| Asset | Dimensions | Description |
| --- | --- | --- |
| [Feature Graphic](google-play/feature-graphic.png) | 1024 × 500 RGB | “WardPulse” and “AI usage at a glance” at left. At right, an unfolded device shows the Codex Dashboard beside a round watch with the three-band WardPulse face. |
| [Store icon](../../../brand/icons/wardpulse-play-icon-512-transparent.png) | 512 × 512 RGBA | The WardPulse mark on a transparent background. |

Use the graphic in the Feature Graphic field and the icon in the app icon field.
[Play Console graphics requirements](https://support.google.com/googleplay/android-developer/answer/9866151)

The owner supplied both files on 2026-11-25, and they were added on 2026-11-28. The Feature
Graphic's device and Dashboard follow the earlier [Foldable cover](../store-foldable/0-cover.png);
the watch was added with image editing on 2026-11-25. On 2026-11-28 its watch face was replaced
with the three-band capture from the [Wear OS gallery](../store-wear/README.md), projected onto
the same dial area. The rest of the graphic is unchanged, including the rainbow floor reflection
below the watch: it is an abstract reflection retained from the original art and does not follow
the new ring order. The icon lives with the other brand icons; see the
[brand directories](../../../brand/README.md#directories).

`69% · 63%`, and the Wear Glance has a Claude / Fable row. Refresh them before use.

All exports use a dark studio background and the existing WardPulse mark. Set the ad headline and
call to action in Reddit Ads Manager. Preview the placement with the intended destination.
