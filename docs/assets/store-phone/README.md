# Phone store gallery

Google Play phone listing, in upload order. All files are 1080 × 1920 RGB PNGs and show sample
usage data in the dark theme. The covers place app captures inside illustrated, unbranded hardware.

Slots 0–5 follow the owner's current upload set, supplied on 2026-11-25. Slots 1–5 are
byte-identical to the supplied copies. Slot 0 is the supplied cover with its watch face replaced
on 2026-11-28, as described below. Slots 1 and 2 were captured on an Android emulator on
2026-11-24 (Europe/Paris). Slots 3–5 were added to the repository on 2026-11-28. Their PNG
metadata records image processing at 15:19, 15:20 and 15:25 on 2026-11-25 (Europe/Paris). They
show the app in the dark theme on the Widget and Providers tabs; slot 3's Codex and Cursor
readings match slots 1 and 2. The capture device and app build for slots 3–5 are not recorded.

| Slot | File | Content |
| --- | --- | --- |
| 0 | [Cover](0-cover.png) | Unfolded phone with Dashboard, a phone with the home widget, and the watch face. |
| 1 | [Dashboard](1-dashboard-dark.png) | Codex weekly capacity, purchased credits and token usage history with its date range. |
| 2 | [Home widget](2-home-widget-dark.png) | Four rows with Codex weekly capacity and credits, OpenAI spend and both Cursor allowances. |
| 3 | [Widget settings](3-widget-settings-dark.png) | Widget tab. Cursor Models 98% left, Other Models 80% left and Codex Weekly plan 54% left are checked. Purchased credits has no percentage to show. Anthropic platform Today, USD 0.79 of a USD 4.97 cap, is unchecked. |
| 4 | [Alert thresholds](4-alert-thresholds-dark.png) | Alerts · Codex plan dialog with the Plan threshold menu open: Off, 100%, 50%, 30%, 20%, 10% and 0% left, and Custom % left. |
| 5 | [Weekly budget](5-weekly-budget-dark.png) | Budget · OpenAI · Platform reporting dialog over the Providers tab, with a USD 10.00 week limit and empty Today and Month fields. |

[Alternate cover](0-cover-alternate.png) shows the Dashboard and widget phones in front of the
unfolded phone, with the watch face at right. It is not part of the current upload set. As it stood
on 2026-11-24, it remains the source of the Combined Reddit ads in the
[advertising assets](../advertising/README.md).

On 2026-11-28 the watch face in both covers, which still showed the paused Claude plan, was
replaced with the three-band capture from the [Wear OS gallery](../store-wear/README.md). The
capture was projected onto the same dial with matching softness; no pixel outside the dial changed.
