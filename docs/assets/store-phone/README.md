# Phone store gallery

Google Play phone listing, in upload order. Choose one cover for slot 0. All files are
1080 × 1920 RGB PNGs. The screenshots were captured on an Android emulator on 2026-11-24
(Europe/Paris) and show sample usage data. The covers place app captures inside illustrated,
unbranded hardware.
